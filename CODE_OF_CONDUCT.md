# Code of Conduct

## Standard

VECTIS welcomes technical disagreement, critical review, and rigorous debate. Participation remains professional and focused on the work.

Contributors are expected to:

1. Treat other participants with respect.
2. Critique code, design, evidence, and behavior rather than individuals.
3. Keep technical discussions relevant to the project.
4. Avoid harassment, threats, discriminatory conduct, and deliberate disruption.
5. Protect private security reports, credentials, and personal information.
6. Respect maintainer decisions while using the documented review process to challenge technical conclusions.

## Enforcement

Maintainers may edit, hide, lock, or remove project interactions that violate this standard and may restrict participation when conduct materially harms the project or its contributors.

Reports involving security vulnerabilities follow [SECURITY.md](SECURITY.md). Conduct concerns should be raised privately with the repository owner when possible.
