# VECTIS Support

## Usage questions

Start with:

* `README.md`

* `docs/README.md`

## Bugs

Use the GitHub bug-report template and include:

* VECTIS version,
* Python version,
* operating system,
* minimal `.vectis` source,
* command executed,
* expected behavior,
* actual diagnostics or runtime result.

Do not include secrets.

## Feature requests

Use the feature-request template. Requests that affect syntax, semantics, capabilities, or runtime authority should describe the intended contract rather than only the desired implementation.

## Security reports

Use the process in `SECURITY.md`; do not file sensitive vulnerabilities as ordinary public issues.
