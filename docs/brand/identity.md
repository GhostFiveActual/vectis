# VECTIS Product Identity

## Official identity

The product name is **VECTIS**.

The public product lockup is:

**Ghost Five // VECTIS**

## Official slogan

**A language for turning what you intend to happen into a system that can prove how it will happen.**

The slogan describes the product contract at the user level: intent enters the language, VECTIS gives it structure, and the execution path remains visible enough to inspect and prove.

## Technical promise

VECTIS is a deterministic automation language and execution toolchain built around visible plans, explicit authority, stable diagnostics, and inspectable runtime behavior.

## Product personality

VECTIS should feel disciplined, technical, operational, and distinct. Excitement comes from watching real execution state become visible rather than from decorative complexity.

## Visual direction

| Element | Standard |
| --- | --- |
| Primary color | Abyssal Teal |
| Alternate accent | Void Amethyst when a second accent is required |
| Base environment | Deep black and graphite with restrained technical texture |
| Interface motif | Mission control, topology, telemetry, authority, execution |
| Motion | Functional motion tied to execution state |
| Character art | Not part of the default VECTIS product identity |

## Interface language

Use operational verbs that map directly to behavior: Check, Compile, Plan, Inspect, Execute, Trace, Format, Test, Export, Authorize, and Review.

Status language describes real state. READY, EXECUTING, AUTHORIZED, REVIEW, FAILED, BLOCKED, SKIPPED, and COMPLETE are appropriate when those states are true.
