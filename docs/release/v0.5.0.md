# VECTIS v0.5.0

VECTIS 0.5.0 introduces deterministic multi-file source modules so reusable pure logic can scale beyond a single mission file without weakening inspection, reproducibility, or explicit authority.

## Imports

```vectis
import "../lib/readiness.vectis";
```

Paths resolve relative to the importing file. Resolution stays inside the nearest VECTIS project root identified by `vectis.toml`, or inside the entry file directory when no project manifest is present.

## Pure module contract

Imported source files may contain imports and top-level pure function declarations only. Executable statements are rejected before graph generation, preventing an import from hiding mission behavior or runtime authority.

## Deterministic module graph

Transitive imports are resolved in source order. Canonical paths are loaded once. Missing modules, absolute paths, paths outside the project root, invalid extensions, and import cycles fail closed.

```bash
vectis modules missions/main.vectis
```

The command exposes the entry file, module root, ordered module list, and module count.

## Project workflow

`vectis init` creates a project with a reusable `lib/` module and a mission that imports it. `vectis test` performs module-aware validation across the project.

Compilation, checking, execution, Mission Control, inspection, plan auditing, graph export, determinism verification, timelines, and reports all resolve the same module graph.

## Authority

Imports are a compile-time source-composition mechanism. They do not create execution nodes, grant filesystem capability, search environment paths, access the network, or inherit ambient runtime authority.

## Compatibility

Existing single-file source remains valid. Pure functions and structured values retain their previous meaning. The 0.5 compatibility line fixes the module path and cycle semantics documented in COMPATIBILITY.md and RFC 0002.

## Verification

CI validates Python 3.11 through 3.14, repository policy, reachable-history privacy, module regression coverage, package builds, and isolated-wheel execution of a mission that imports a separate VECTIS module.
