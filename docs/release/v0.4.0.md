# VECTIS v0.4.0

VECTIS 0.4.0 makes structured mission state a first-class part of the language syntax while preserving the deterministic value model, pure-function model, execution graph, runtime, and explicit authority boundaries established by earlier releases.

## Structured literals

Lists and objects can be authored directly:

```vectis
source build {
    passed: true,
    coverage: 96,
    checks: [true, true, true]
};
```

Object keys may be identifiers or quoted strings. Values may be nested structured expressions.

## Member and index access

Structured values can be read without constructor-specific lookup calls:

```vectis
let coverage build.coverage;
let first_check build.checks[0];
let quoted build["coverage"];
```

Invalid member types, missing members, invalid index types, and out-of-range list indices fail explicitly.

## Pure functions

User-defined pure functions can accept, construct, return, and inspect structured values while retaining explicit parameters and compile-time expansion.

```vectis
function summarize(build) {
    return {
        coverage: build.coverage,
        first_check: build.checks[0]
    };
}
```

## Compatibility

The 0.4 language remains compatible with structured constructors and lookup built-ins introduced earlier. `list(...)`, `object(...)`, `get(...)`, `has(...)`, `keys(...)`, `values(...)`, and `size(...)` remain supported.

## Determinism and authority

Structured syntax is pure computation. It does not create action nodes, inherit environment state, perform I/O, or acquire filesystem, process, HTTP, or other capability authority.

The syntax is represented in the typed AST, validated before graph generation, expanded through pure functions when needed, preserved in canonical formatting, evaluated through the deterministic runtime, and visible in reports and plan evidence.

## Verification

The release gate covers parsing, semantic validation, deterministic evaluation, pure-function integration, graph dependency discovery, runtime structured-value propagation, formatting round trips, package build, isolated-wheel CLI execution, and Python 3.11 through 3.14 compatibility.
