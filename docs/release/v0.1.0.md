# VECTIS v0.1.0

VECTIS v0.1.0 is the first open source release of the deterministic automation language and execution toolchain.

## Language and execution

The release provides a complete source to execution path with a lexer, parser, typed syntax tree, semantic analysis, deterministic execution graph, runtime state tracking, explicit branching, assertions, computed values, stages, deterministic built in functions, and capability-aware execution boundaries.

Large execution plans are covered by regression tests above 300 nodes. Operators can apply explicit node, edge, and depth budgets so oversized plans fail closed before execution.

## Plan verification

Every compiled execution graph can produce a stable SHA-256 fingerprint. The same valid source and compiler behavior produce the same canonical plan identity.

```bash
vectis fingerprint examples/showcase/full-release-assurance.vectis
vectis limits examples/showcase/full-release-assurance.vectis \
  --max-nodes 200 \
  --max-edges 400 \
  --max-depth 100
```

## Human operation

Mission Control presents the same runtime data used by structured automation interfaces in a human focused execution view.

```bash
vectis mission examples/showcase/full-release-assurance.vectis
```

Named stages group complex plans into readable operational sections. Execution reports provide portable HTML evidence containing plan identity, graph metrics, runtime states, resolved values, failures, and published results.

```bash
vectis report examples/showcase/full-release-assurance.vectis \
  --output vectis-execution-report.html
```

## Visual applications

`vectis studio` launches Mission Control Studio for visual authoring, validation, graph inspection, runtime telemetry, diagnostics, and language reference.

`vectis demo` launches the interactive VECTIS application demonstration backed by the same compiler and runtime.

## Toolchain

The CLI includes validation, token inspection, AST inspection, execution planning, structured execution, Mission Control, canonical formatting, expression evaluation, graph export, structural explanation, fingerprints, complexity limits, HTML reports, project scaffolding, project validation, examples, REPL access, environment diagnostics, and application launchers.

## Security and authority

Filesystem, process, and HTTP effects remain behind explicit capability boundaries and bounded adapters. The runtime does not use host language `eval` or `exec`, does not provide implicit shell execution, and does not implicitly inherit the parent process environment for bounded process execution.
