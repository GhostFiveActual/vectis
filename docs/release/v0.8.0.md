# VECTIS 0.8.0

VECTIS 0.8.0 establishes the first release baseline on the clean canonical repository and adds editor-facing language intelligence without changing the deterministic runtime or authority model.

## Highlights

* Dependency-free Language Server Protocol endpoint through `vectis lsp`.
* Compiler-backed syntax and semantic diagnostics.
* Canonical whole-document formatting.
* Registry-backed completion for keywords, built-ins, and standard actions.
* Hover documentation sourced from shared language and action metadata.
* Typed-AST document symbols for functions, missions, stages, declarations, and actions.
* Project-aware validation for saved files with imports.
* Isolated-wheel release smoke coverage for LSP initialization, advertised capabilities, shutdown, and clean exit.
* Clean canonical Git history beginning from one audited parentless VECTIS root commit.

## Compatibility

The 0.8 release is additive relative to the 0.7 language and runtime contract. Existing VECTIS missions, action profiles, deterministic plan fingerprints, explicit capability boundaries, and standard action behavior remain compatible.

No editor feature grants runtime authority. The LSP uses the same parser, semantic analysis, formatter, built-in registry, action registry metadata, and typed AST as the command-line toolchain.

## Verification

The release is accepted only after the repository quality gate, the Python 3.11 through 3.14 CI matrix, package build, isolated wheel installation, CLI smoke tests, LSP protocol smoke tests, public-tree checks, and reachable-history privacy audit pass.
