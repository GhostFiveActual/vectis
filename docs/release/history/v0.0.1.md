# VECTIS v0.0.1

**Ghost Five**

VECTIS v0.0.1 is the first packaged release baseline of the deterministic, capability-aware VECTIS language and execution toolchain.

## Highlights

* deterministic source parsing and execution-graph compilation,
* semantic validation before execution,
* explicit dependency and conditional branch edges,
* deterministic runtime scheduling,
* source-reference condition execution,
* dry-run execution,
* explicit capability registry,
* bounded filesystem, process, and HTTP adapters,
* structured diagnostics with source positions,
* installable Python package with the `vectis` CLI.

## CLI

```text
vectis check FILE
vectis parse FILE
vectis plan FILE
vectis run --dry-run FILE
vectis run FILE
vectis --version
```

## Validation baseline

The release line was validated with:

* 311 repository tests,
* the complete VECTIS quality gate,
* a clean clone on a second system,
* editable installation,
* independent VECTIS authoring and runtime execution,
* wheel and source-distribution builds,
* wheel installation into a fresh environment,
* execution from outside the source checkout.

## Artifacts

The release workflow publishes:

* `vectis_lang-0.0.1-py3-none-any.whl`
* `vectis_lang-0.0.1.tar.gz`

## Scope

v0.0.1 is an early engineering release. Its purpose is to establish a tested language/compiler/runtime/package baseline before broader syntax, adapter, ecosystem, and compatibility expansion.
