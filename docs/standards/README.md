# VECTIS Project Standards

## Purpose

These standards define how VECTIS source, documentation, tests, releases, and contributions are maintained.

The objective is consistency. A contributor should be able to understand what a file does, what behavior a test protects, what authority a runtime action requires, and what evidence is required before a release.

## Standards

| Document | Purpose |
| --- | --- |
| [Engineering](engineering.md) | Repository structure, implementation discipline, comments, tests, and quality gates. |
| [Writing](writing.md) | Documentation and product voice. |
| [Language](language.md) | Language design and compatibility rules. |
| [Release](release.md) | Validation, packaging, versioning, and release evidence. |

## Operating rule

If behavior cannot be explained, tested, and inspected, it is not ready to ship.
